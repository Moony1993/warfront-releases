# Warfront

Ein düsteres Eroberungsspiel: Baue deine Heimat auf einer Welt, die an Ketten im Nichts hängt, stelle deine Armee aus Kasernen und Gruften auf und erobere die Karte gegen die Reiche anderer Spieler.

## Spielen

1. Unter **[Releases](../../releases/latest)** die neueste `Warfront-x.y.z-windows.zip` herunterladen.
2. Entpacken und `Warfront.exe` starten.
   Windows SmartScreen fragt beim ersten Mal nach: **Weitere Informationen → Trotzdem ausführen**.
3. Im Hauptmenü unter **Optionen** deinen **Spielernamen** und den **Server-Schlüssel** eintragen (den bekommst du privat).

Mit Schlüssel spielst du gegen die Läufe deiner Freunde (Online-Ghosts), ohne Schlüssel offline gegen Bots.
